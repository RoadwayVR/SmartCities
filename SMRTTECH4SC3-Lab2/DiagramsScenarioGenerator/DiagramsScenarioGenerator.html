SUMO Scenario Builder

Prepare a complete SUMO scenario for fundamental-diagram data collection. The builder copies the full scenario, creates the edgeData output setup, and automatically sets the simulation step length to 0.2 s.
Use Microsoft Edge or Google Chrome. Choose the original SUMO scenario folder and an output location. Your original files are not modified. After preparation, open the generated ..._FD.sumocfg in SUMO-GUI and run it.
Direct folder writing is not supported by this browser.

1. Choose original SUMO scenario

Select the folder containing the .sumocfg, .net.xml, .rou.xml, and other scenario files.

2. Choose output location

A new prepared scenario folder will be created here.
